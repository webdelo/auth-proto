# auth-proto

gRPC contract definitions for the [webdelo/auth](https://github.com/webdelo/auth) service.

## Overview

This repository hosts the **`auth.v1`** gRPC contract (proto file + generated Go stubs) for the Webdelo authentication service. The contract is extracted into its own repository so that external consumers (SDKs, BFFs, third-party clients) can depend on the contract without pulling in the entire AUTH server module.

**Why a separate repository:**

- **Low coupling.** Consumers (such as `webdelo/auth-client-go`) import only the contract stubs without the AUTH server's transitive dependencies.
- **Drift protection.** Server and clients compile against the same tagged contract version.
- **Multi-language ready.** Today the repository ships Go stubs in `go/`. PHP/TS subdirectories can be added later without migrations.
- **Clean surface for contractors.** Client teams can be granted access to this repository (plus the relevant client SDK) without seeing the AUTH server.

## Layout

```
auth-proto
├── proto/
│   └── auth_service.proto       # source contract (package auth.v1, 13 RPCs)
├── go/                          # Go submodule
│   ├── go.mod                   # module github.com/webdelo/auth-proto/go
│   ├── go.sum
│   └── auth_v1/
│       ├── auth_service.pb.go        # generated by protoc-gen-go
│       └── auth_service_grpc.pb.go   # generated by protoc-gen-go-grpc
├── Makefile                     # target generate-go
├── .gitignore
└── README.md
```

## Prerequisites

| Tool | Version | Install |
|------|---------|---------|
| `protoc` | 34.1+ | https://github.com/protocolbuffers/protobuf/releases |
| `protoc-gen-go` | v1.36.11 | `go install google.golang.org/protobuf/cmd/protoc-gen-go@v1.36.11` |
| `protoc-gen-go-grpc` | v1.6.1 | `go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@v1.6.1` |
| Go | 1.24+ | https://go.dev/dl/ |

Ensure `$(go env GOPATH)/bin` is on your `PATH` so `protoc` can find the plugins.

## Generation

```bash
make generate-go
```

This produces `go/auth_v1/auth_service.pb.go` and `go/auth_v1/auth_service_grpc.pb.go`, then runs `go mod tidy` in `go/`.

To verify the module builds:

```bash
make verify
```

## Versioning

The Go submodule uses **directory-prefixed semver tags** following the [Go modules submodule convention](https://go.dev/ref/mod#vcs-version):

```
go/v0.1.0   # current
go/v0.2.0   # backward-compatible additions
go/v1.0.0   # first stable release (when the contract is frozen)
```

### Release process

1. Edit `proto/auth_service.proto` (mind backward compatibility — field numbers, message order, reserved tags).
2. Run `make generate-go`.
3. Commit `proto/`, `go/auth_v1/`, `go/go.mod`, `go/go.sum`.
4. Tag: `git tag go/vX.Y.Z && git push origin go/vX.Y.Z`.
5. Bump the dependency in consumer repositories (`require github.com/webdelo/auth-proto/go vX.Y.Z`).

## Consumers

| Repo | Role |
|------|------|
| [`webdelo/auth`](https://github.com/webdelo/auth) | Server. Imports stubs as `github.com/webdelo/auth-proto/go/auth_v1`. |
| [`webdelo/auth-client-go`](https://github.com/webdelo/auth-client-go) | Go SDK — thin wrapper over `auth_v1.AuthServiceClient`. |
| `webdelo/auth-client-php` (future) | PHP SDK — generated from `proto/`. |
| `webdelo/auth-client-ts` (future) | TypeScript SDK — generated from `proto/`. |

## Installation

This repository is public — no authentication required. Add as a Go module dependency:

```bash
go get github.com/webdelo/auth-proto/go@latest
```

Or pin a specific tag:

```go
// go.mod
require github.com/webdelo/auth-proto/go v0.1.0
```

Tags follow the [Go submodule convention](https://go.dev/ref/mod#vcs-version): `go/v0.1.0`, `go/v0.2.0`, etc. — see [Versioning](#versioning).
